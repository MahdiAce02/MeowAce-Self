# 🐱 MeowAce-Self

نسخه سبک شده و رایگان ربات AceSelf، بهینه شده برای بازی میویی بدون آپشن‌های اختصاصی با پشتیبانی از سیستم تک‌سشن و **مولتی‌سشن (Multi-Session)** با ربات مدیریت تلگرام.

---

## 🌟 ویژگی‌ها (Features)

1. 🐈 **AutoCatch (نجات خودکار گربه‌های خیابونی):**
   - کلیک آنی بر روی دکمه نجات هنگام دریافت پیام جدید.
   - قابلیت تنظیم تاخیر (delay) و تعداد تلاش روی ادیت پیام (times).

2. 🐱 **AutoMeow (ارسال خودکار کلمات میویی):**
   - ارسال خودکار کلمات (مع، میو، ...) و تشخیص هوشمند زمان کولداون از پاسخ ربات.

3. 🎣 **AutoFish (ماهیگیری خودکار):**
   - حمایت از تمام حالت‌ها: غذادادن به پیشی (`feed`)، فروش مستقیم (`sell`) و ذخیره در یخچال (`fridge`).
   - قابلیت تشخیص پر بودن یخچال و فروش جایگزین.

4. 🧊 **AutoFridge (مدیریت خودکار یخچال):**
   - پختن ماهی‌های خام و سپس فروش (`sell`) یا غذادادن (`feed`).
   - خواب خودکار در صورت خالی بودن یخچال.

5. 👁️ **Show Mode (حالت مخفی‌سازی پاسخ‌ها):**
   - خاموش کردن پاسخ به دستورات بازیکن جهت عدم شناسایی ربات توسط ادمین ها و حذف آنی کامند.

6. ⏰ **Message Scheduler (زمانبندی پیام‌ها):**
   - زمانبندی یک پیام دلخواه بر روی سرور های تلگرام جهت آنلاین نشدن اکانت در کامند هایی نظیر automeow.

7. 🔗 **Command Alias (میانبر دستورات):**
   - تعریف اسم کوتاه و میانبر بر روی دستورات مختلف برای اجرای سریع‌تر.

8. 🤖 **Multi-Session System (مدیریت چندحسابه با ربات تلگرام):**
   - پشتیبانی از اجرای همزمان چندین حساب کاربری مجزا بدون تداخل اطلاعات و کانفیگ‌ها.
   - لاگین تعاملی از طریق ربات تلگرام (دریافت کد OTP و 2FA در چت ربات).
   - ذخیره امن API ID و API Hash هر کاربر برای ورودهای بعدی.
   - جداسازی کامل سشن‌ها و تنظیمات ماژول‌ها per-user.
   - پشتیبانی از حالت‌های خصوصی (Private Whitelist) و عمومی (Public Free/Paid).
   - سیستم خرید اشتراک کارتی (پرداخت کارت‌به‌کارت با تایید دو مرحله‌ای فیش واریزی توسط ادمین).
   - سیستم تست رایگان (Trial) با قابلیت تنظیم مدت زمان (به ساعت).
   - قطع سشن و لاگ‌اوت خودکار هنگام انقضای اشتراک همراه با حفظ تمام کانفیگ‌ها و الیاس‌های کاربر.

9. 📊 **Status & Help:**
   - دستور `/status` برای مشاهده وضعیت کلی ماژول‌ها در چت جاری.

## 🛠️ پیش‌نیازها و نصب (Prerequisites & Installation)

- پایتون نسخه 3.8 یا بالاتر
- دریافت `API ID` و `API HASH` از سایت [my.telegram.org](https://my.telegram.org)

### 1. نصب خودکار تک‌خطی با curl در لینوکس

جهت دانلود مستقیم لایو سورس از گیتهاب و نصب خودکار در VPS فقط دستور زیر را وارد کنید:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/MahdiAce02/MeowAce-Self/main/setup.sh)
```

یا در صورت دانلود دستی سورس:

```bash
bash install.sh
```

در اسکریپت نصب می‌توانید بین دو حالت زیر انتخاب کنید:
- **حالت تک‌سشن (Single-Session):** استفاده از یک حساب تلگرام شخصی با `config.json`.
- **حالت مولتی‌سشن (Multi-Session):** راه اندازی ربات مدیریت جهت ورود و استفاده همزمان چندین کاربر.

### 2. تنظیمات مولتی‌سشن (`bot_config.json`)

در صورت فعال کردن `"multi_session": true` در فایل `config.json`، فایل `bot_config.json` ایجاد می‌شود:

```json
{
  "bot_token": "YOUR_BOT_TOKEN",
  "admin_id": 123456789,
  "bot_api_id": 123456,
  "bot_api_hash": "YOUR_BOT_API_HASH",
  "card_number": "6037997000000000",
  "mode": "private",
  "public_type": "paid",
  "subscription": {
    "price_toman": 50000,
    "duration_days": 30
  },
  "trial": {
    "enabled": true,
    "duration_hours": 24
  }
}
```

#### حالات کاری ربات مدیریت:
- **`mode: "private"` (پیش‌فرض):** فقط کاربرانی که آیدی آن‌ها توسط ادمین در وایت‌لیست قرار گرفته باشد (`/addwhitelist <user_id>`) می‌توانند لاگین کنند.
- **`mode: "public"`:** تمامی کاربران می‌توانند با ربات تعامل داشته باشند.
  - **`public_type: "free"`:** دسترسی رایگان به همه کاربران داده می‌شود.
  - **`public_type: "paid"`:** کاربران برای لاگین نیاز به خرید اشتراک یا فعال‌سازی تست رایگان دارند.

#### روند پرداخت و تایید کارت‌به‌کارت:
1. کاربر در ربات گزینه «💳 خرید اشتراک» و سپس «📌 درخواست شماره کارت» را کلیک می‌کند.
2. ادمین پیامی مبنی بر درخواست خرید دریافت کرده و آن را تایید اولیه می‌کند.
3. شماره کارت به همراه مبلغ برای خریدار ارسال شده و از او خواسته می‌شود عکس فیش را ارسال کند.
4. خریدار فیش واریزی را فرستاده و عکس فیش برای ادمین ارسال می‌شود.
5. ادمین فیش را تایید کرده و اشتراک کاربر (مثلاً ۳۰ روز) به طور اتوماتیک فعال می‌شود.

## 🌐 تنظیمات پروکسی (Proxy Settings)

اگر ترافیک تلگرام روی سرور یا کامپیوتر شما فیلتر/بلاک است، می‌توانید انواع پروکسی **SOCKS5** ،**HTTP** یا **MTProto** را به یکی از روش‌های زیر ست کنید:

### روش ۱: استفاده از اسکریپت `install.sh`

دستور زیر را اجرا کنید و گزینه `[7]` را انتخاب کنید:

```bash
bash install.sh --proxy
```

### روش ۲: تنظیم مستقیم در فایل `config.json`

```json
{
  "multi_session": false,
  "api_id": 123456,
  "api_hash": "YOUR_API_HASH",
  "proxy": {
    "enabled": true,
    "type": "socks5",
    "host": "127.0.0.1",
    "port": 1080,
    "username": "",
    "password": ""
  }
}
```

## 🎮 راهنمای دستورات سلف‌بات (Command Guide)

تمام دستورات را می‌توانید مستقیماً در هر چت یا گروه تلگرام ارسال کنید:

### 🐱 AutoMeow

- `/automeow instant` ── فعال‌سازی میو خودکار در لحظه (حالت زنده ⚡)
- `/automeow schedule [1 - 90]` ── زمانبندی روی سرور تلگرام جهت عدم آنلاین شدن اکانت (حالت زماندار 📅 تا ۹۰ پیام)
- `/automeow off` ── غیرفعال‌سازی در چت جاری

### 🎣 AutoFish

- `/autofish feed schedule` ── ماهیگیری زماندار سرور و غذادادن به پیشی (عدم آنلاین شدن 🛡️)
- `/autofish sell schedule` ── ماهیگیری زماندار سرور و فروش مستقیم ماهی (عدم آنلاین شدن 🛡️)
- `/autofish fridge schedule` ── ماهیگیری زماندار سرور و ذخیره در یخچال (عدم آنلاین شدن 🛡️)
- `/autofish [feed|sell|fridge] instant` ── حالت لحظه‌ای زنده ⚡
- `/autofish off` ── غیرفعال‌سازی در چت جاری

### 🧊 AutoFridge

- `/autofridge sell schedule` ── پخت و فروش زماندار سرور بر اساس زمان پخت (عدم آنلاین شدن 🛡️)
- `/autofridge feed schedule` ── پخت و غذادادن زماندار سرور بر اساس زمان پخت (عدم آنلاین شدن 🛡️)
- `/autofridge [sell|feed] instant` ── حالت لحظه‌ای زنده ⚡
- `/autofridge off` ── غیرفعال‌سازی در چت جاری

### 🐈 AutoCatch

- `/autocatch on` ── فعال‌سازی نجات خودکار گربه خیابونی
- `/autocatch off` ── غیرفعال‌سازی نجات خودکار
- `/autocatch delay 2` ── تنظیم تاخیر کلیک (بین ۰ تا ۱۰ ثانیه)
- `/autocatch times 2` ── تنظیم تعداد کلیک مجدد هنگام ادیت پیام (بین ۱ تا ۳ بار)

### 👁️ Show Mode

- `/show off` ── خاموش کردن پاسخ به دستورات جهت عدم شناسایی ربات توسط ادمین ها
- `/show on` ── روشن کردن پاسخ و نمایش خروجی وضعیت دستورات

### ⏰ Scheduler

- `/sched [count] [interval_mins] [message]` ── زمانبندی پیام بر روی سرور های تلگرام

### 🔗 Command Alias

- `/alias add [نام الیاس] [دستور مقصد]` ── تعریف اسم کوتاه و میانبر بر روی دستورات مختلف
- `/alias del [نام الیاس]` ── حذف الیاس
- `/alias list` ── مشاهده لیست الیاس‌های ثبت شده
- `/alias clear` ── پاکسازی کامل الیاس‌ها

### 📊 Status

- `/status` یا `/help` ── مشاهده وضعیت تمام ماژول‌ها در چت فعلی
